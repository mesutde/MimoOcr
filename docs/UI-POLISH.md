# UI güncellemeleri — tema, diller, toplu, credits

## Toplu
- Buton sırası: **Dosya ekle… · Çıktı klasörü · Temizle**
- Varsayılan kayıt: **Ayrı ayrı** (kullanıcı isterse Birleştir)

## Tema
- Varsayılan: **Koyu (dark)**
- Başlıkta **◐** — açık/koyu geçiş
- Ayarlar → **Tema** seçimi
- Tercih `localStorage` ile hatırlanır

## OCR dilleri (Ayarlar)
- Motorların desteklediği diller `engine_status.languages` ile gelir
- tessdata (tur, eng, …) + Windows OCR dil paketleri
- Liste örneği: `Türkçe + English`, `Türkçe (tur)`, `English (eng)`, …
- Motor kapasitesi arttıkça diller otomatik eklenir
