# Arayüz dilleri (UI i18n)

## Davranış
- **Varsayılan: English**
- Açılışta **işletim sistemi dili** okunur (`navigator.language`)
  - OS `tr` → Türkçe
  - OS desteklenen başka dilse o dil
  - Aksi halde **English**
- Tercih **Ayarlar → Interface language / Arayüz dili** ile değişir ve hatırlanır

## Desteklenen arayüz dilleri
| Kod | Dil |
|-----|-----|
| en | English (varsayılan) |
| tr | Türkçe |
| es | Español |
| fr | Français |
| de | Deutsch |
| pt | Português |
| zh | 中文 |
| ja | 日本語 |
| ar | العربية |

Bu diller dünya nüfusunda en çok konuşulan/ arayüzde sık kullanılan dillerdir.

## OCR dili ayrıdır
Ayarlar’daki **OCR language** motorun tanıdığı metin dilidir (tessdata / Windows paketi).  
**Interface language** sadece arayüz metinleridir.

## Yer
- **Ayarlar** sekmesi: birinci alan **Interface language**
- OS diline göre otomatik seçim + elle değiştirme
