# Toplu motor/kalite + sade Ayarlar

## Toplu sekmesi
Kayıt alanının yanına:
- **Motor** — varsayılan **Tesseract** (`tesseract-cli`)
- **Kalite** — Dengeli / Yüksek (2×)

Toplu işlemi artık kendi motor ve kalite değerlerini kullanır (başlıktaki motoru takip etmez).

## Yakala sekmesi
- **Kalite** alanı buraya taşındı (Dengeli / Yüksek)
- **Panoya kopyala** da Yakala’ya eklendi

## Ayarlar — sadeleşti
Kaldırılanlar (zaten ana ekranda var):
- Motor seçici
- Kalite
- Tema (başlıkta ◐)
- Panoya kopyala

Kalanlar:
- **OCR language** (tüm sekmeler için ortak)
- Motor dil bilgisi
- Künye (MiMo-X Pro · Mesut Demirci · LinkedIn)

## Deneme
1. Toplu → **Motor** ve **Kalite** görünür, motor **Tesseract**
2. Ayarlar → yalnız OCR dili + künye
3. Yakala → Monitör + Kalite + Kopyala
